# ADR-0002 — 宿主无关的专业证据引擎

2026-11-25 接受。长期主线采用路线 B，优先通过通用 MCP 服务向 DSH、Codex 等 Agent 提供 GC 的专业证据工作流。执行范围和发布状态由[当前阶段](../current-phase.md)维护。

## 决定

GC 持有发现、排序、核读、确定性组包与引用绑定各自的阶段合同。宿主决定如何理解问题、是否补查、何时停止和怎样作答。模型和宿主可以独立替换。独立应用及正式 Generation 继续提供完整问答和可复现对照。通用聊天前端以维护为先。

封装整个 G5 可以保留完整问答，也会将 GC 的模型许可和研究循环带进宿主。只返回检索命中会让每个宿主重新处理条件、父级、预算和引文。路线 B 复用已经验证的证据责任，同时允许在相同上游比较不同研究策略。历史 G7 表明，模型可能遗漏已经回读的原文；排序研究也记录了补进一段证据时换出另一段独立证据的代价。[G7 审计](../research/clean-generation-g7-70q-quality-audit-20261117.md) · [排序研究](../research/clean-rerank-disagreement-20261124.md)

## 采用依据

依次评估回答正确性、关键证据完整性、检索效率与响应速度、运行成本。工程回放验证原文和引用传递。真实回答及跨宿主收益需要另行配对和原文复核。宿主消息、模型判断和行动轨迹均保持派生身份。首期边界见[离线合同](../phases/mcp-offline-v1.md)。
