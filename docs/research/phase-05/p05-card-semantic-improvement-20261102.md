## 根因与实际传播

以两份审计为起点，回查最终审阅集的实际作业输入、原文锚点、阅读卡与综合依赖；首次审计关于固定False的负面外推以反向审计的撤回为准。

- **3470《白夜国馆藏》**：直接阅读作业 `327b76295d5f…` 已同时读到赫利俄斯落成和“大日御舆最早的名字是赫利俄斯”，仍把命名关系作为假说，并将神车/高塔的措辞差异当成反证。随后 `aa9f193fa6e6…` 和文档作业 `4a4204528970…` 延续该说法，问题又派生为clue。这里既有阅读判断错误，也有综合未据明确引文纠正错误。
- **399《捕风的异乡人》**：早期阅读作业 `97c7addbff53…` 只有拦路少女、任务目标及使用安柏的操作说明，未直接交付“少女名为安柏”；当时保留身份疑问并非同等严重的误判。后续 `0a254ad33795…`、`ebdb5565bcbe…`、文档作业 `c737c306bdcc…` 传播疑问；最终实际输入已经交付安柏自报姓名及“少女名为安柏”，却仍称“缺少姓名或直接指认”。**随着证据增加，疑问应当更新，不能因来自子卡便被固化。**
- **507877《月下的守望者》**：`00a72df038cb…` 等阅读/综合作业反复将安排承接整体悬置，最后 `72dea107244d…` 继续列为假说/问题。叶洛亚“按照他自己的愿望”已经说明承接；“一月值夜”与“保护在建灯塔”的工作细节是否完全相同仍可保留未知。原审计将其与前两例同等定罪，过于严厉。

旧提示对避免错认身份、无证确证的要求充分，但对“文本已明确陈述就应记录”的要求不足；“合成时不可创造子卡未有的事实”容易被理解为不得修正子卡。以上是有档案支持的机制判断，不能排除模型自身选择性忽略证据，不能证明提示词是唯一原因。

## 最小机制修改

### 证据判断

沿用现有字段，不扩大Schema或增加审核流水线：

| 判断 | 放置与边界 |
| --- | --- |
| 原文直接陈述 | source_observations，modality说明文本明确如何命名/指认/承接；不无故降级为假说 |
| 人物或文献声称 | source_observations，明确谁、在哪种叙事中声称什么；不升级为客观史实 |
| 合理推断 | interpretations；具体而待证的命题可进hypotheses，说明缺口和反证 |
| 缺乏证据 | 不产生肯定观察、不凭空凑假说；必要时在limitations或具体问题中记录缺失 |

明确区分命题的局部确定与局部未知。歌谣、小说、反事实及人物证言仍有各自的模态；相似称呼和跨故事镜像不构成身份同一证明。这些分类由提示指导，modality仍是模型填写的自然语言，**不是程序已裁定的结构化真值或官方来源标签**。

### 综合优先核对实际原文

新策略将 `inherited_anchors` 和 `source_context` 放在 `children` 前，标明子卡判断可错；综合可依据实际交付的引文纠正子卡的分类、归属和遗漏。source_context来自原证据的章节、类型、选择器、结构、来源角色和provenance，保留分支及不同故事的上下文；unknown仍为unknown。

没有暗中补交全文。综合仍只能引用实际继承的精确anchor_id，不能创造或模糊匹配引文；引用合同继续使用card-evidence-selection-4。未被子卡保存为锚点的原文仍不可由综合猜出，必要时须定向重读。

新语义策略关闭跨旧策略的整篇/范围自动复用，避免旧产物因机械合格而跳过新语义判断；同一新策略的精确请求缓存与恢复仍可复用。旧策略及历史档案的恢复行为不变。已有子卡可以作为明确交付的综合输入，不能自动获得新策略语义合格标记。

### 非剧情选读

新策略在原结构选读基础上排除**明确**占位、纯数值、技术root_id、带数字的显式机制规则及现实时间接取任务的操作说明，记录每个省略范围及理由。不会以一个“伤害”关键词过滤整段，不过滤剧情对话中的人物指令，也不把孤立人名扩写成剧情。

装备描述按原文行保留未识别为噪声的内容，不再要求出现“曾/传说/故事”等触发词，也不因出现伤害词或文字很短就丢掉叙事。混合而无法确定的正文保留，交给带来源模态的阅读判断。

### 覆盖状态

新建Card的 `whole_page_semantic_coverage` 为null，配合 `semantic_coverage_status=NOT_ASSESSED`；不是改成true。另给 `selected_scope_delivery`：COMPLETE / PARTIAL / EMPTY_SELECTION / NOT_PLANNED，记录所需字符、交付或继承字符和缺失的选读范围。

该统计只核算绑定RU范围，不代替“可达且成功的阅读依赖”检查，更不测量理解或重要剧情抽取是否完整。政策省略和upstream_skips分别保留。历史54份的False原样保留，离线旁表将其解释为“旧常量，语义未评估”；54份既定选读交付均完整，不据此认证Canonical整页语义完整。

## 剩余风险与定向重生成评估

1. **实际效果待测**：模型仍可能忽略直接引文、过度推断或混淆模态。特意保留了一项测试，展示“错误断言巫女确有儿子”仍可能因引用合法而机械通过；没有伪装成程序已解决语义真伪。
2. 综合只能利用已交付锚点，无法恢复子卡从未引用的关键原文。来源provenance未知、人物代词和跨分支时序的不确定性仍存在。顺序调整和来源上下文是改善条件，不能保证模型按要求使用它们。
3. 窄范围筛选仍会留下部分目录和机制，也可能漏判新形式的操作说明；混合文本保留是有意的取舍，不引入宽泛的人名/剧情分类器。覆盖null表示未评估；没有计算语义准确率或全文理解率。
4. **需要后续定向实测，但不需要重跑54份。** 建议下一轮单独授权后，先对这六例各做一次匹配原范围的阅读/综合对照，固定1017及当前渠道，最多6个新逻辑请求、保留原稿、不自动重发UNKNOWN；同时检验三例关系纠正与三例反向边界。三个正例的最终综合已拥有所需直接锚点，可先验证综合纠错，不必先全篇重读。若同时通过，再仅重建受影响阅读/综合祖先及派生clue；若锚点不足才定向重读相应范围。当前没有执行或授予这六次调用的许可。
