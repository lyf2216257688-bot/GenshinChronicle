# Phase05 R1-QA — candidate semantic review and quote reliability

Status: **COMPLETE with explicit residuals; human semantic acceptance OPEN**, 2026-10-25. Current authorization is owned by
`docs/current-phase.md`. This study preserves R1 immutable artifacts and all
existing uncommitted work. No production RAG, full knowledge production or KG

## Initial frozen design — interrupted Qwen cohort (historical)

The complete existing R1 Top20 union, including all repeat/query-only arms,
scope and same-body controls, original 959 pairs and supplemental/reference
pairs, contains 3,445 directional source pairs, 3,304 unordered pairs and
36,000 discovery records across 1,019 source pages. Directional discoveries,
rankings and old outcomes remain separate from source-pair deduplication.
Source identity/snapshot determines pair identity; model interpretations do
not merge distinct sources or assert semantic equivalence.

Both `qwen3.7-plus-2026-05-26` and `qwen3.8-max` are scheduled to independently
review every recoverable source pair. They receive identical verified snippets
with source titles but no method, rank, target proposals or legacy judgments.
They select snippet IDs; code extracts exact original text and source/RU
locators. Reject and insufficient require both endpoint selections for a full
mechanical PASS. Mechanical PASS, model review and human acceptance are
separate fields; all human acceptance starts NOT_REVIEWED.

The richer literary rubric permits useful anchored interpretations without
calling them confirmed history. Generic themes, unsupported identity/cause,
gameplay-only correspondence, missing evidence and duplicate witness claims
are assessed separately. Two Qwen reviews are not independent human gold or
cross-family model replication. Agreement on verdict does not prove agreement
on every claim.

Canonical source hashes and complete selected-occurrence RU reconstruction are
verified before passage creation. Narrative selection reuses R1's scoped body
policy; 64 pages without that body receive explicitly labelled rich-text
context, not an invented narrative role. Long contexts have a deterministic
24,000-character per-side limit with explicit omissions. No Canonical text is
repaired; exact character offsets and hashes own quotations.

Main artifacts: `data/retrieval/p05-navi-r1-qa-20261025-r1/`.
The protocol is fixed before model dispatch. It schedules approximately 6,608
reviews, with caps of 9,000 model reservations, 120 million accounted/reserved
tokens, RMB 2,000 conservative accounting and 100 UNKNOWNs. The existing 20%
unknown ratio guard is supplemented by a 5% guard after 20 UNKNOWNs. No UNKNOWN
or issued-but-unresolved request is automatically retried; only positively
proven pre-header failures permit bounded reconnects. Both models are planned
for all pairs rather than being a failure-triggered fallback. Accounting rates
are ceilings, not verified provider tariffs or invoices.

The first eight scheduled reviews test the delivery contract and retain their
normal job identities/results in the full study. Resolved malformed outputs
remain explicit failures; no hidden repair/retry is planned. R1's unresolved
requests remain quarantined; the new source-ID review is a separately
authorized different semantic contract, not a reissue of its old payload.

Invalid IDs remain invalid; relation labels are never silently remapped.

## 3. 来源层级控制

Raw 频道图已与自身 metadata SHA 核对：189=图鉴，190=观测，62=观测·考据，243=观测者教学，68=书籍。1,021 页中，835 页为图鉴类别、121 页明示考据/分析、19 页为其余观测材料、46 页为其他/未分类。

552 个 useful 中有 78 个涉及考据/观测材料。它们可能有研究导航价值，但不能作为独立游戏剧情证词；筛去这些标记后还剩 474 个模型 useful，其中 466 个两端都在图鉴类别，173 个至少一端为书籍类别。图鉴类别也可能包含编辑汇编或混合正文，**不等于已经逐段证明为游戏原文**。

该来源分层是在发现问题后追加的透明诊断，不是预注册金标准。没有因“小说/传说”文体就拒绝材料；也没有把考据文章自动判错。所有原始评分保留，所有检索候选继续留在分母中，不重排、不补足被筛材料的位置。

DeepSeek 的 literary_value 对 551 个 useful 为 true，定义偏宽；其中 relation=literary_parallel 为 347 个。不能把这些数字称为“已识别并证实的文学隐喻数量”。

### 双向机制、桥梁与稳定性

同一 A0 信息、模型、向量和查询预算下，保留集局部 Top20：双向独有 2 个 useful，合并独有 6 个；放宽旧引文 gate 的 locator 条件则为 0 对 5。全库融合条件严格版双向多2个，但 locator 版反而少2个，未呈现稳定优势。

桥梁有 1,605 条路径成员记录，去重为 662 个来源三元组；50 个三元组的两条边都被模型判 useful，614 个至少达到 useful/tentative。后者大部分仍是待定，不能当成可靠历史推理链。路径成员关系不证明是哪条查询造成最终排名，A—M 与 M—B 也不推导 A/B 身份或因果。

原 R1 排名 Top20 重复平均 Jaccard：普通画像0.686、A0合并0.655、双向0.477。新复审后的有价值边集合重复 Jaccard：普通0.833～0.882、A0合并0.650～0.792、双向0.217～0.500；这是小范围、源/目标画像同时变化的诊断，不是普适稳定性保证。

顺序模拟三种顺序分别有126、119、117个模型useful，但没有为全部128个新资料起点建立相同原文/改写到达对照，不能把更多边数解释成双向机制胜出；来源ID顺序也不是发布日期或剧情时间线。

### 仍保留的比较限制

- 128份画像与全库原文的范围先验、不同词法统计、旧画像引文裁剪都没有被本轮重新生成消除。已使用同范围、同正文、query-only等现有对照，而没有重做R1。
- 新旧Qwen文档向量的几何差异仍未定位。查询型比较共享原文索引和同批查询向量，较少混入“新画像文档向量vs旧原文向量”的差异；仍不能据此证明远端权重未变。
- Qwen和DeepSeek有366条可比较的部分观察，评级一致154条；分歧显著，且样本受额度中断限制。模型认可不能替代人工金标准。格式澄清只增加格式约束，不是第二个完整独立审稿人。
- 未测最终剧情问答、Evidence Packet准入、生产重排或正式知识生产收益。
- 本轮评分单位是来源对的联读价值，不等于原检索已经找准支持段落、原检索解释正确或最终引用已交付。不同解释/关系标签保留为候选，不穷尽所有关系，也不执行全局实体或史实归一。

## 5. 真实案例与可核查增量

- **《水仙之梦》6350 ↔《逐影猎人》500037**：儿童“勇者/恶龙”游戏、院长/副院长的离别，与成年后的童年游戏回忆可具体互读。新模型useful，双端原文已提取；不因此确定每个匿名角色身份。
- **《竹林月夜》1146 ↔《辰砂往生录》3867**：三姐妹、灾祸、高车的组合是具体锚点；后者保留商人不信民间传言的口吻。可讨论叙述差异，不能删掉这些限定直接写成客观历史。
- **《白夜国馆藏》3470 →“龙嗣伪鳍”3392**：物品描述明确记述龙蜥决定特征去留与遗传，馆藏含《深海龙蜥实验记录》。普通画像作查询第5、索引融合第12；原文六查询与改写均不在Top20。这支持资料卡作查询的价值，不是画像索引直接找到未建卡资料。
- **“暗巷闪光”1683 →《古老的考察日志》1441**：A0合并第6、双向第5、桥梁融合第2，普通画像及原文六查询/改写未入Top20。日志对厄伯哈特的阴谋保留叙述者猜测，武器故事补充义贼叙事，身份与因果仍需限定。
- **《竹林月夜》1146 →“天光的纺琴”506378**：普通索引第8、A0/双向第15、桥梁融合第8，三个相应query-only臂和原文六查询/改写均未入Top20。两边“三个月亮”与失落传说是模型判useful的锚点；是画像索引仍有候选增量的例子，不能据此确定人物同一。
- **《醉客轶事》1148 ↔《乐园遗落之花》5404**：新模型仍判tentative。梦、记忆等相似不能自动落实到“仙灵教化者”身份。
- **《如雷的盛怒》1632 ↔“奇特的羽毛”3121**：新模型给tentative，而非把预设目标当作确定正确；后者只有获取说明与任务名，无法单凭它确认少年/阿瑠等身份。它可能是导航线索，不是剧情证词。

上述“useful”均是模型层判断；Codex对源码与真实文本的定向阅读也不是独立人工认可。精简盲审包包含10例，覆盖强锚点、泛化隐喻、身份风险、一二手材料、方法新增和跨模型分歧。

## 6. 第一版建议（研究结论，未实施）

**推荐：结构感知轻量资料卡 → 缓存查询视图 → 原文Lexical/Hybrid候选 → B双来源复核 → 分级导航候选。**

1. **资料卡值得建设**：以适中密度的内容画像、具体细节和源片段ID为主。其作为查询的结果优于本轮普通改写，且保留集有13个不在原文六查询+改写Top20并集中的模型useful，不能说简单改写已经覆盖全部价值。
2. **原文检索+缓存改写仍是强主干**：无需先建立复杂知识图；语义资料卡可提供另一种查询表达，与改写互补，尚不能宣布最终QA已足够。
3. **画像专用索引有增量，暂不设为第一版必需**：确有原文可回查的新候选，但本次128子集固定融合总体损失较大。可保留小型合并索引为辅助研究臂，不优先全库正式生产或默认强融合。
4. **A0字段可选，双向专用索引暂缓**：保存有依据的问题、信息供给和意象即可；不强制每份资料填满，也不把角色硬过滤的局部结果视为普遍优势。
5. **桥梁作有限研究工具**：少数具体文学联系有价值，但多数链仍待定，工程与B复核成本增加，不作为默认多跳。V的覆盖账/交付检查点可复用；主动探索、自动触发、KG及线上融合暂缓。
6. **分开事实与解释**：useful也可只是有锚点的文学对应；tentative进入研究队列，一二手来源分开，精确引用从Canonical/RU抽取。原文定位成功不能批准身份/因果，也不能自动获得人工认可。
