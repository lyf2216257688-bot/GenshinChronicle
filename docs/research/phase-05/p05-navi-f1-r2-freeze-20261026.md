## 4. 新鲜性检查：机械结果与语义判断

这次对候选来源的**完整Canonical全部rich text**筛查，包括未交付成长/攻略部分，
不通过选择一个较干净的局部来掩盖全页污染。
50个初选端点加2个补充端点接受全文筛查；1042历史Canonical均核验过原文件hash。
最终48源再次核验上游及冻结快照hash。

方法和实际结果：

- 对至少12字符的完整原文行做去空白精确匹配，既覆盖短关键说明，也记录数字和通用文案；
  两批共1,100条命中，每条保存新旧端section/unit及归一化定位，不把匹配定位冒充引文坐标。
- 对长段以char5gram取top12后做近重复检查：最短60字且ratio至少0.80，或连续相同至少90字。
  首批2,853次近比较命中1条武器效果文案，补充批无近命中；命中逐条有处置。
- 最终48源与旧1042源的完整rich-body归一化hash无相同项。
- 去除展示后缀的同名检查发现娜维娅角色页／洞天页，定向阅读旧500419。
  旧页已有裙摆不妨碍行动的描述；新洞天对话则讲设计师的改良要求，二手文章讨论现实风格。
  同人物、衣装语义邻近明确披露；本次测试核心为双来源实际内容及现实原型到游戏历史的推论边界，
  未发现旧校准对该组合命题的复述。它不是改名重发或同一正文版本，不宣称人物从未在历史资料出现。
- 定向检索作者、作品、具体角色及事件名称，区分旧正文、二手转述和目录标签。
  既有handbook问候规范引用、记者相关NPC目录、食品/任务目录均有命中，不能写成全无历史提及。

《骑士团指导手册》的旧命中主要是问候用语、壁饰说明和目录链接；本次飞行执照/安全规则及
条件用语测试未发现相同的历史核心。小说《薇拉》则在历史考据中实际被展开讨论，故保守排除。
两者处置基于内容覆盖与测试核心，不仅看来源类别或是否出现作品名。
这些边界判断均为agent取样判断，完整记录供复核，不能据机械无命中证明所有转述均不存在。

短于阈值、跨行非完整句及未命中短名单的改写仍有检测限制。来源家族定向检视补充这些机械检查，
不是全库别名系统、KG或独立人工审定。
