# P04-W1 Canonical Corpus Profile

> Historical research note: represents the P04-W1 read-only profiler output.
> Current production/default status is owned solely by `docs/current-phase.md`.

The JSON aggregate generated by the Phase 04 read-only profiler over the
accepted Phase 03 Canonical run is recorded at
`data/retrieval/p04-w1-phase03-batch5b-corpus-profile.json`. It is evidence for
representation and benchmark experiments, not a permanent OBC schema,
semantic-role taxonomy, or retrieval decision.

The profiler reads the Canonical manifest in order, reads each referenced record
once, verifies its SHA-256 against the manifest, and retains only aggregates.
It does not rerun projection or write Canonical records.

The report intentionally counts exact repeated text only as occurrences. It
does not merge equal text or identify equal text with equal evidence.
