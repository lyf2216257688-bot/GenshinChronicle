# GC 本地聊天产品 V1

此合同定义独立的 Windows 个人聊天入口。当前工程与试用状态见 [当前阶段](../current-phase.md)。

Starlette 和 Uvicorn 复用现有 Generation UI 运行环境，接口和页面由同一个本机进程提供。Vue、TypeScript 和 Vite 用于开发及构建，日常启动直接加载随软件交付的静态页面。

- 浏览器通过同源 /api/v1 访问会话、草稿、轮次、事件、引用、反馈和有限批次。服务只监听 IPv4 回环。界面操作与展示可独立替换。
- 产品数据根默认 `data/generation/personal-chat-v1`，可由启动器 `--root` 指定。应用持久配置、会话、批次、证据回执、反馈和执行记录都由该根管理。会话 ID 持久稳定，提交令牌在同一会话内幂等。消息、上下文、已发布结果和来源使用原有不可变引用及哈希。每个新轮次绑定其提交时的独立批次。旧轮次继续使用原许可、预算和检查点。读取、刷新、重开与 SSE 重连仅展示已有状态。
- MOCK 使用有标识的合成材料。LIVE 使用 Clean G5、S0、bge_structural 和官方 deepseek-flash。用户显式开启有限批次，复用原许可校验、接入控制、model_calls 账本与 UNKNOWN 处理。历史实验不作为应用数据库打开。
- 当前轮次引用只从已发布结果取得，按 turn、Packet、E 编号验证。用户反馈与证据和模型输入独立保存。来源身份和语义支持分别评价。
- 本地软件工程验收、有限真实问答试用和默认 Serving 采用分别记录。

## 接口与恢复约定

[产品契约](../../frontend/openapi.json)同时用于服务端校验与 [TypeScript 类型](../../frontend/src/api/generated.ts)生成。服务端返回每轮的执行状态、是否有正式回答、停止原因、可用操作和事件游标。读取历史只加载所选页，打开引文时再核验原 Packet、阅读回执及父级身份。

凭据保存接口仅接受产品合同已验证的 DeepSeek 官方路由。官方基础地址和同域兼容写法归一到 `https://api.deepseek.com/chat/completions`。服务端用 Windows 当前账号保护 API Key，只在产品数据根保存密文。运行时接口只返回状态、实际端点和数据目录。保存配置只写本机，付费请求由独立的有限批次授权。有本机配置时优先使用它，无本机配置时沿用启动环境 `DEEPSEEK_API_KEY`。损坏或无法解密的本机配置应在页面更换或移除。页面修改凭据前须关闭可用的真实问答批次，真实批次绑定凭据来源或本机配置版本。

提交令牌由服务端随草稿发放。重发同一提交可取回同一轮，复用令牌修改问题或覆盖其他窗口已保存的新草稿会返回冲突。进度流接受 `Last-Event-ID` 或初始 `after`，使用持久化序号跳过重复内容。

应用重开时，将先前尚在执行或排队的轮次标为中断。可继续的轮次须由用户显式恢复。未恢复的轮次保留原许可和账目，其他已获许可的新轮可以执行。执行适配、路由配置或上游代码变化时，原真实批次进入只读，重新开启的有限批次供后续新轮使用。

来源面板给出原句及相应条件。仅当原数据明确给出说话者时显示其名称。反馈包含轮次、原问题、不可变回答哈希和可选的 Packet 引用，重访时核对版本。软件操作与验收复现入口见[本地聊天说明](../local-chat.md)。
