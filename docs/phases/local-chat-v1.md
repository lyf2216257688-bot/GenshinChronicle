# GC 本地聊天产品 V1

此合同定义独立的 Windows 个人聊天入口。当前工程与试用状态见 [当前阶段](../current-phase.md)。

Starlette 和 Uvicorn 复用现有 Generation UI 运行环境，接口和页面由同一个本机进程提供。Vue、TypeScript 和 Vite 用于开发及构建，日常启动直接加载随软件交付的静态页面。

- 浏览器通过同源 /api/v1 访问会话、草稿、轮次、事件、引用、反馈和有限批次。服务只监听 IPv4 回环。界面操作与展示可独立替换。
- 产品数据根默认 `data/generation/personal-chat-v1`，可由启动器 `--root` 指定。应用持久配置、会话、批次、证据回执、反馈和执行记录都由该根管理。会话 ID 持久稳定，提交令牌在同一会话内幂等。消息、上下文、已发布结果和来源使用原有不可变引用及哈希。每个新轮次绑定其提交时的独立批次。旧轮次继续使用原许可、预算和检查点。读取、刷新、重开与 SSE 重连仅展示已有状态。
- MOCK 使用有标识的合成材料。LIVE 使用 Clean G5、S0、bge_structural 和官方 deepseek-flash。用户显式开启有限批次，复用原许可校验、接入控制、model_calls 账本与 UNKNOWN 处理。历史实验不作为应用数据库打开。
- 当前轮次引用只从已发布结果取得，按 turn、Packet、E 编号验证。用户反馈与证据和模型输入独立保存。来源身份和语义支持分别评价。
- 本地软件工程验收、有限真实问答试用和默认 Serving 采用分别记录。

## 接口与恢复约定

[产品契约](../../frontend/openapi.json)同时用于服务端校验与 [TypeScript 类型](../../frontend/src/api/generated.ts)生成。服务端返回每轮的执行状态、是否有正式回答、停止原因、可用操作和事件游标。读取历史只加载所选页，打开引文时再核验原 Packet、阅读回执及父级身份。

运行时接口包含 `api_revision`。修订号 4 增加引用正文与父级上下文的状态和定位。启动器只复用同一数据目录且版本相符的实例，页面遇到旧接口时提示重新启动本机服务。

凭据保存接口仅接受产品合同已验证的 DeepSeek 官方路由。官方基础地址和同域兼容写法归一到 `https://api.deepseek.com/chat/completions`。服务端用 Windows 当前账号保护 API Key，只在产品数据根保存密文。运行时接口只返回状态、实际端点和数据目录。保存配置只写本机，付费请求由独立的有限批次授权。有本机配置时优先使用它，无本机配置时沿用启动环境 `DEEPSEEK_API_KEY`。损坏或无法解密的本机配置应在页面更换或移除。页面修改凭据前须关闭可用的真实问答批次，真实批次绑定凭据来源或本机配置版本。

提交令牌由服务端随草稿发放。重发同一提交可取回同一轮，复用令牌修改问题或覆盖其他窗口已保存的新草稿会返回冲突。轮次、提交引用与作业在同一事务入库。执行器从数据库按提交顺序单路领取，在子进程启动前幂等补齐用户消息和提交事件。单轮补写或启动失败会挂起该轮，后续排队仍能推进。

进度流接受 `Last-Event-ID` 或初始 `after`，使用持久化序号跳过重复内容。SQLite 暂时占用返回 `503 storage_busy`，已知的记录完整性故障返回 `409 integrity`，意外服务错误返回 JSON `500 internal_error`。流已开始后的读取错误通过错误事件报告。客户端通过轮次读取接口核对持久状态，仍在处理时从最新游标重新连接。

删除会话在产品数据库写入删除标记。同一会话的历史、草稿、轮次入口与关联反馈随后对应用隐藏，已保存的证据、调用记录和账目保留用于审计。删除请求可重发，正在执行或排队的会话须先停止并等待任务结束。

应用重开时，将先前尚在执行或排队的轮次标为中断。可继续的轮次须由用户显式恢复。未恢复的轮次保留原许可和账目，其他已获许可的新轮可以执行。执行适配、路由配置或上游代码变化时，原真实批次进入只读，重新开启的有限批次供后续新轮使用。

在兼容的 G5 产品批次内，本地查询写入 `local_attempts/`，封存并核验后原子发布到 `local_queries/`。显式继续可在原轮次内重做没有发布的本地查询，已发布的排名按原封存重放。发布绑定或封存损坏时阻断。停止和关批保留已发生的模型占额，UNKNOWN 保持原状态。升级为不兼容的执行适配时，旧批次与检查点继续按原绑定只读，已提交问题、正式答案、证据及账目保留。

选用 G5 证据质量策略的运行将共享调用账本判定的 UNKNOWN 写入轮次摘要。界面使用现有停止原因和占额字段显示远端结果未知。传输诊断留在本机尝试记录，API 和前端契约维持修订号 4。

纠正按目标消息及记录的依赖生效。上下文保留仍有效的用户要求和范围纠正，并按批次的字节预算纳入近期对话、可选的历史剧情纠正、旧摘录和同会话研究。当前对话预算为 24,000 字节，以紧凑 UTF-8 JSON 计量，完整请求及证据预算另行校验。提交前以同一投影检查当前问题和必须保留的条件，超限返回 `422 context_budget_exceeded` 并保留草稿和提交令牌。原话、旧证据引用和审计用省略记录可在本机回查。同轮恢复复用已经发布的上下文快照。

来源面板给出入包的原句及相应条件。仅当原数据明确给出说话者时显示其名称。已保存的自然父级单独展开，显示其是否属于作答 Packet，并提供自己的文本位置。由 G5 证据质量策略作答时，父级可在发布前按已绑定的引用补存。它以独立的哈希回执关联当前轮次和 Packet。补充上下文读取失败或历史定位不全时显示实际覆盖状态，仍可读取可验证的原引用。反馈包含轮次、原问题、不可变回答哈希和可选的 Packet 引用，重访时核对版本。软件操作与验收复现入口见[本地聊天说明](../local-chat.md)。
