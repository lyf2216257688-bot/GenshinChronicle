- **Query Seam**: Arbitrary Dense/Hybrid queries use Qwen synchronous query seam (`role=query`, dimension 2048, dense-only). Fail-closed on missing credentials or transport errors.
- **Provider Calls**: Authorized ONLY when explicitly granted in the active work unit. SDK retries are disabled. Newly integrated offline tasks use the shared call layer in `docs/model-interfaces.md`; UNKNOWN isolates the task and consumes its reservation, while explicit bounded duplicate-cost risk authorization can permit retry. No such paid recovery is authorized in this work unit. The following runner-specific rules are historical/legacy policies, not new shared defaults. For new E2 execution, explicit model AND matching route are required, with no default/fallback; E2 application retry is bounded to three attempts on the same route/model only for the exact proven pre-generation TokenMetro TPM 429 rejection. The separate v0.3 runner permits at most three identical attempts only with complete archived proof of TCP/TLS pre-header non-transmission; any HTTP response, UNKNOWN, stream/content failure or pending reservation prohibits reissue. This policy implementation does not authorize a call. Historical experiment policies remain frozen.
- **Audit Lineage**: Every provider request and raw response must be preserved immutably.
- **Corpus Integrity**: No silent rewriting, normalization, or pruning of Raw or Canonical evidence.
- **Scope Discipline**: No premature adoption of Vector DB, ANN, KG, AI Semantic Extraction, or UI expansion.
