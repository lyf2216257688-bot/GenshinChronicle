# 使用 GC 本地聊天

在项目根目录双击 **Start-GC-Chat.cmd**。启动器使用项目已有的 Generation Python 环境和随源码交付的页面，在默认浏览器中打开 `http://127.0.0.1:17861/`。重复双击会打开已有实例。日常使用只需保留这个服务窗口，关闭标签页后仍可从同一地址回到聊天。

## 开始和接续讨论

1. 首次使用可点 **体验离线演示**。演示使用小型合成资料，适合熟悉发送、追问、查看原文和反馈的操作。
2. 讨论实际剧情时点 **新建对话** 或首页的 **开始真实对话**。进入 **开启问答批次**，确认请求上限、时长和费用授权。启动软件的环境需要已有的 `DEEPSEEK_API_KEY`。批次面板会列出缺少的本地资产。模型、索引和运行环境见[工作台运行前提](rag-workbench.md#运行前提)。
3. 输入问题，按 Enter 发送，Shift + Enter 换行。可直接追问“这个判断依据是什么？”。要让一个条件在后续轮次保持有效，勾选 **补充条件**。要撤回原来的说法，在那条消息下点 **纠正这条** 或 **纠正回答**，选择剧情前提或讨论范围，再提交修订。历史中仍能看到双方原话。
4. 第二天再次双击启动器，从侧栏打开原会话。草稿自动保存。若旧批次到期，开一个新批次，在同一会话发送下一条即可。可以在不同会话之间切换，或在顶部为会话改名。

### 批次、停止和恢复

- 真实问答沿用 G5 官方模型接线。每批可选 **2–10 次模型请求，有效 1–120 分钟**。同模式下的所有会话共享同一个开放批次。一轮可能包含多次查证和生成请求。面板显示已占请求数、已知 Token、批次上限和用量未知的次数。
- 已提交的轮次继续在本机服务中运行。刷新、切换会话、重新打开页面都从已保存的进度接续显示。要停止点击 **停止本轮**。关闭整个批次会停止该批次未结束的轮次，已发出的请求保留实际结果和占额。
- 要退出整个应用，在启动服务的控制台按 **Ctrl+C**。重开后，仍可继续且原许可有效的轮次显示 **继续本轮**。只有点此按钮才按原操作与原检查点继续。远端结果未知时，原操作保留占额，界面显示 **远端结果未知**。新批次可用于同一会话的新问题。

### 引用和反馈

点回答中的 **E01** 等引用按钮，打开本轮证据、父级原文、可用的说话者或条件及来源定位。不同轮次都可以有 E01，按钮始终指定本轮及其证据包。**查证过程** 展示检索问题、阅读次数和资料取舍。部分完成的轮次可以有正式答案，未发布的流式文字单独标为草稿。

点回答下的 **反馈** 或来源面板中的 **反馈此引用**，选择回答错误、证据遗漏或引用问题并填写说明。在侧栏 **反馈记录** 中可回到原回答版本及所指引文。没有绑定编号时，回答会说明缺少可打开的引用。来源校验失败时可直接针对这处引用反馈。即使能读到原句，仍需结合语境判断它能否支持回答。

## 本机数据

默认目录为 `data/generation/personal-chat-v1/`，首次启动时创建。备份时先退出服务，再复制整个目录，其中包含会话、草稿、原文回执、回答版本、反馈、批次许可和调用记录。恢复到原路径可以保留运行许可与检查点中的绝对路径绑定。预装资产和历史工作台目录登记在[数据目录](../data/README.md)。

端口冲突时，可在项目根目录用 PowerShell 启动其他端口。指定自定义数据根时选空目录或此前由此程序创建的产品目录。

```powershell
.\Start-GC-Chat.cmd --port 17862
```

## 开发与验收

`src/genshin_corpus/local_chat/contract.py` 定义产品接口和校验模型。运行时接口说明位于 `/api/v1/openapi.json`。前端开发使用 Node.js 24 及项目锁定的 npm 依赖。修改契约后，在仓库根目录用 PowerShell 重新生成类型并构建页面。

```powershell
$env:PYTHONPATH = 'src'
$py = '.\.local\runtime-py314\generation\Scripts\python.exe'
& $py -B -m genshin_corpus.local_chat.contract
Push-Location frontend
npm ci
npm run types
npm test
npm run build
Pop-Location
```

后端产品测试使用项目临时目录与小型夹具。可选的官方接线测试用本机已有协议证明开启临时许可，使用内存传输，并在测试内禁止外部套接字连接。浏览器测试需要本机 Microsoft Edge，自动选择空闲端口并重启独立测试服务。

```powershell
$env:PYTHONPATH = 'src'
$env:GC_TEST_LOCAL_PROFILE = '1'
& .\.local\runtime-py314\generation\Scripts\python.exe -B -m unittest discover -s tests/local_chat -v
Push-Location frontend
npm run test:browser
Pop-Location
```

前端的 `src/api/` 负责传输和类型，`src/chat/actions.ts` 负责可注入客户端的聊天操作，`src/chat/state.ts` 负责会话、草稿、进度和面板状态。后续按 Figma 设计改版，可从 `src/components/`、`src/App.vue` 和 `src/styles.css` 入手，用同一组操作测试与浏览器场景回归。
